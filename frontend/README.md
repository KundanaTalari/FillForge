# FillForge frontend

React, TypeScript, Vite, and Tailwind user interface.

## Run

```powershell
cd frontend
npm install
npm run dev
```

During local development, Vite proxies API calls to `http://127.0.0.1:8000`.

For a separately deployed backend, set `VITE_API_BASE_URL` in `.env` using `.env.example` as the guide.
